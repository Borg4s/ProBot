
# BOT DE LOJA AUTOMÁTICA DISCORD

## Instruções:

1. Instale os requisitos:
   pip install -r requirements.txt

2. Configure seu TOKEN, ADMIN_ID e IDs de canais no bot.py.

3. Rode o bot:
   python bot.py

4. Comandos disponíveis:
   - !painel (só para admins)
   - !atualizarloja (para atualizar a loja nos canais)
